# CBP – Collaborative Web Project

## 📌 Project Overview
CBP is a student group project developed collaboratively to demonstrate practical web development skills. The project uses frontend technologies to create a web-based application.

## 🚀 Technologies Used
- HTML5 – Structure of the application
- CSS3 – Styling and user interface
- JavaScript – Application functionality

## 📂 Project Structure
```text
CBP/
│
├── index.html
├── style.css
├── app.js
└── README.md
```

## ✨ Key Components
- **index.html:** Defines the structure of the web application.
- **style.css:** Handles the design, layout, and styling.
- **app.js:** Implements application functionality.

## 💻 How to Run the Project

1. Clone the repository:

```bash
git clone https://github.com/Santoshkumar-09/CBP.git
```

2. Open the project folder:

```bash
cd CBP
```

3. Open `index.html` in your web browser.
